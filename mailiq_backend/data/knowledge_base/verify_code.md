# Verify Code / OTP Emails

Verification code emails contain one-time passwords (OTPs), 2FA codes, magic login links, or account activation tokens. They are almost always HIGH priority because codes expire quickly (usually 5-10 minutes).

Never share a verification code with anyone — legitimate services never ask you to read out or forward an OTP over the phone, chat, or email.

If you receive a verification code you did not request, it means someone else is trying to log into your account. Ignore the code, then immediately change your password for that service.

SMS-based OTPs are more phishing-resistant than email OTPs. If a service offers SMS 2FA, prefer it over email-based verification for important accounts.

Magic login links (passwordless auth) expire even faster than OTPs — open them immediately or restart the login flow to get a fresh link.
